## Project Structure

The project is now organized into logical directories for better maintainability:

### Root Level
- **hardhat.config.js** - Hardhat configuration
- **package.json** - NPM dependencies and scripts
- **package-lock.json** - NPM lock file
- **.env** - Environment variables (API keys, RPC URLs, private keys)
- **LICENSE** - MIT License
- **README.md** - Main project documentation

### Core Directories

#### `/contracts` 
Smart contracts organized by module:
- **token/** - ONBT token contracts
  - `OmnichainNabatOFT.sol` - Main OFT contract (32 lines, minimal, clean)
- **defi/** - DeFi-related contracts
- **governance/** - Governance contracts
- **nft/** - NFT contracts
- **oracle/** - Oracle contracts
- **treasury/** - Treasury contracts
- **libraries/** - Shared libraries
- **compose/** - Composition patterns

#### `/scripts` (Hardhat scripts)
Deployment and utility scripts:
- `simple-deploy-onbt.mjs` - Deploy to Base
- `simple-deploy-arbitrum.mjs` - Deploy to Arbitrum
- `configure-new-peers.mjs` - Configure bidirectional peers
- `configure-new-enforced-options.mjs` - Set enforced options
- `configure-multiple-dvns.mjs` - Configure DVNs
- `apply-config-dvns.mjs` - Apply DVN config from config file
- `set-config-via-endpoint.mjs` - Set config via LayerZero endpoint
- `verify-new-deployment.mjs` - Verify deployment on both chains
- Plus 30+ other utility scripts

#### `/deploy` (Deployment artifacts)
All deployment-related files:
- **deployment-*.json** - Deployment records for each chain
- **verify-*.js** - Contract verification arguments
- **verify-*.cjs** - CommonJS verification scripts
- **check-*.js** - Deployment checks
- **configure-*.js** - Configuration helpers
- **deploy-*.js** - Standalone deployment scripts
- **update-*.js** - Update utility scripts
- **debug-*.js** - Debugging utilities

#### `/config` (Configuration files)
- **layerzero.config.ts** - LayerZero OApp configuration with DVN settings
  - Contains contract addresses on both chains
  - Required and optional DVN configurations
  - Executor addresses
  - Block confirmations
- **tsconfig.json.bak** - TypeScript configuration backup

#### `/docs` (Documentation)
All markdown documentation and references:
- **ARCHITECTURE.md** - System architecture
- **IMPLEMENTATION_GUIDE.md** - Implementation steps
- **DEPLOYMENT_GUIDE.md** - Deployment instructions
- **LAYERZERO_CONFIGURATION_COMPLETE.md** - LayerZero setup status
- **OPTIONAL_DVNS_CONFIGURED.md** - DVN configuration status
- Plus 60+ other comprehensive documentation files

#### `/tasks` (Hardhat tasks)
Custom Hardhat tasks:
- Task definitions and implementations

#### `/test` (Tests)
Test files for all contracts

#### `/examples` 
Example implementations:
- `agentkit-example.mjs` - Coinbase AgentKit example
- `cdp-sdk-example.mjs` - CDP SDK example
- `multi-chain-example.mjs` - Multi-chain example

#### `/integrations`
Integration examples for different chains:
- `/arbitrum` - Arbitrum specific code
- `/avalanche` - Avalanche specific code
- `/bsc` - BSC specific code
- `/coinbase` - Coinbase specific code
- `/ethereum` - Ethereum specific code
- `/optimism` - Optimism specific code
- `/polygon` - Polygon specific code

#### `/miniapp`
Mini application (React):
- `App.tsx` - Main React component
- `/components` - React components
- `/config` - Mini app configuration
- `/public` - Static assets

#### `/constants`
Application constants:
- `layerzero.mjs` - LayerZero constants and addresses

#### `/assets`
Application assets:
- `/branding` - Logo and branding files

#### `/artifacts` (Generated)
Compiled contract artifacts (auto-generated by Hardhat)

#### `/cache` (Generated)
Build cache (auto-generated by Hardhat)

#### `/node_modules` (Generated)
NPM dependencies

### Key Files Extracted to Root

Nothing - root is intentionally minimal with only:
- Configuration files (hardhat.config.js)
- Package management (package.json, package-lock.json)
- Environment (.env)
- License and README

### Configuration Locations

**Import paths have been updated:**
```javascript
// Old (❌)
import config from "../layerzero.config.ts";

// New (✅)
import config from "../config/layerzero.config.ts";
```

Scripts that use this import:
- `scripts/apply-config-dvns.mjs`
- `scripts/set-config-via-endpoint.mjs`
- `scripts/init-and-set-config.mjs`

## Quick Commands

```bash
# Compile contracts
npx hardhat compile

# Deploy to Base
npx hardhat run scripts/simple-deploy-onbt.mjs --network base

# Deploy to Arbitrum
npx hardhat run scripts/simple-deploy-arbitrum.mjs --network arbitrum

# Configure peers
npx hardhat run scripts/configure-new-peers.mjs --network base

# Set enforced options
npx hardhat run scripts/configure-new-enforced-options.mjs --network base

# Verify deployment
npx hardhat run scripts/verify-new-deployment.mjs --network base

# View LayerZero configuration
cat config/layerzero.config.ts

# View documentation index
ls docs/
```
